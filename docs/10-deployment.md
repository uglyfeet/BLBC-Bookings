# Deployment

The BLBC Booking System will be developed using Visual Studio Code with version control provided by Git and GitHub.

Once development is complete, the application will be deployed to an online hosting platform.

The deployment process will include:

- Publishing the source code to GitHub.
- Configuring the production environment.
- Deploying the application.
- Verifying that the live application functions correctly.

Detailed deployment steps will be added once the application has been successfully deployed.
