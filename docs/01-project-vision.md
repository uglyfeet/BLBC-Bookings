# Project Vision

## Purpose

The Burton Latimer Baptist Church (BLBC) Booking System aims to provide an easy-to-use online room booking service for both members of the public and church administrators. The church has several rooms available for hire which are currently underused. By providing an online booking system, the church hopes to increase room usage, generate additional income, and reduce the administrative effort required to manage bookings.

## Problem Statement

Currently, room bookings are managed manually, making it difficult to advertise room availability and keep track of reservations. This places additional pressure on church administrators and limits opportunities to generate income from unused facilities.

The proposed booking system will provide a central location where potential customers can view available rooms, check availability, and submit booking requests. Church administrators will be able to review, approve, or reject bookings through a secure administration area, making the booking process more organised and efficient.

## Target Users

The system is intended for two main groups of users:

* **Visitors** who wish to hire church rooms for meetings, events, or community activities.
* **Church administrators** who manage room availability, approve bookings, and maintain booking records.

## Main Features

The booking system will provide the following core features:

* Display available rooms with descriptions, photographs, capacities, and hire charges.
* Allow visitors to check room availability.
* Allow visitors to submit booking requests.
* Provide a secure administrator login.
* Enable administrators to approve or reject booking requests.
* Prevent double bookings by checking room availability.
* Store booking information securely within a database.

## Technologies

The system will be developed using:

* HTML5
* CSS3
* Bootstrap
* JavaScript
* Python
* Flask
* SQLite
* Git and GitHub for version control

## Project Success

The project will be considered successful if it:

* Provides a simple and intuitive booking experience for visitors.
* Reduces the amount of administration required to manage bookings.
* Prevents booking conflicts through automated availability checking.
* Encourages greater use of the church's facilities.
* Creates an additional source of income for Burton Latimer Baptist Church.
* Demonstrates the practical application of modern web development technologies and Python programming.
